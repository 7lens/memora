# Security

Keep credentials and access tokens outside the memory. A note, history event, or HTML export can contain private information.

Keep personal memory on a local branch or a private remote. A branch name does not restrict access. Git history retains deleted notes.

The HTML viewer displays note data as text. It does not execute note HTML or scripts. Exports contain graph metadata and recent event summaries.

For a security report, contact the repository owner through a private channel. Do not put credentials or private notes in a public issue.

The project has no hosted service and no automatic Git synchronization.
