Graph guide

Cluster: a group of notes. The label shows the project, repository, or Shared scope. The number is the note count.

Node: one memory entity. Its color shows its type. Select it to read its source, evidence, history, and links.

Arrow: a typed relation. Its direction shows which entity points to the other. Select a node to show nearby relation labels.

Navigate: select a cluster, then choose Open cluster. Use Expand to show matching entities. Drag to pan, use the wheel or +/- buttons to zoom, and use Fit graph to center visible items.

Filter: project, repository, type, state, score, and search change the visible graph and list. Search also checks tags.
