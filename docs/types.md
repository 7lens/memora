  types:

    Concept: A defined subject or method.
    Fact: A claim that can receive a source check.

    Task: Work with a goal and a completion state.

    Document: A summary of a source document.
    System: Related parts that perform a function.
    Project: Work with a shared purpose.
    Repository: A source code or document repository.

    Checkpoint: The current task progress for a session.

# Entity types

Add a definition to the mapping before you use a new entity type. Keep the definition in STE.

Do not use a tag as a replacement for an entity relation. Use tags for subject classification.

Read [the public standard](standard/README.md) for type semantics and reviewed exchange.
Keep personal and task types out of published knowledge.
